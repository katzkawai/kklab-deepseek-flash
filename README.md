# 浜名湖うなぎ観光情報サイト

静岡県浜名湖のうなぎをテーマにした観光情報サイトです。
浜名湖うなぎの歴史・文化・名店情報を紹介する、静的HTML+CSSで構築したデモサイトです。

## サイト内容

- **ホーム（index.html）**
  - 浜名湖うなぎの魅力紹介（養殖の歴史・蒲焼の文化・名店めぐり）
  - 浜名湖周辺の観光スポット
- **歴史・文化（about.html）**
  - 養殖の歴史
  - 蒲焼の文化と土用の丑の日
  - 浜名湖うなぎの歩み（年表）
- **お店紹介（shops.html）**
  - 浜名湖周辺のうなぎ名店カード
  - 土用の丑の日のおすすめ
  - **※店舗情報はすべて架空のデモ内容です。実在の店舗とは一切関係ありません。**

## ファイル構成

```
.
├── index.html          # ホームページ
├── about.html          # 歴史・文化ページ
├── shops.html          # お店紹介ページ
├── css/
│   └── style.css       # スタイルシート（レスポンシブ対応）
└── README.md
```

## ローカルでの確認方法

```bash
python3 -m http.server 8000
```

上記実行後、ブラウザで http://localhost:8000 にアクセスしてください。
